# legal-ru

Skill-ветка по российскому праву для основателя, который сам себе юрист:
контракты и режим коммерческой тайны (98-ФЗ, NDA), персональные данные
(152-ФЗ), корпоративное (14-ФЗ, корпоративный договор, ЕГРЮЛ) и
досудебное/процессуальное (претензионный порядок, исковая давность).
Интеллектуальная собственность вне периметра — см. `patent-ru`.

Структура и часть формулировок изучены и частично адаптированы из
[`anthropics/claude-for-legal`](https://github.com/anthropics/claude-for-legal)
(Apache-2.0) — см. [NOTICE.md](NOTICE.md). Юридическое содержание не переведено
из этого источника: написано заново, с опорой на собственный реестр норм.

Каждый содержательный результат — черновик для проверки квалифицированным
юристом, а не юридическая консультация.

## Как установить

**Через маркетплейс** (проще всего):
```
/plugin marketplace add serjdrej/ru-legal-skills
/plugin install legal-ru@ru-legal-skills
```

**Отдельно, без маркетплейса** — склонировать репозиторий в директорию
скиллов Claude Code (`~/.claude/skills/legal-ru` — на других CLI-рантаймах
может отличаться, см. их документацию):
```
git clone https://github.com/serjdrej/legal-ru.git ~/.claude/skills/legal-ru
```

## Проверка актуальности нормы

Ни одна запись ни в одном реестре (`references/norms-registry-*.md`) не
сверена по живому источнику — каждая явно это говорит и объясняет, как
перепроверить. Для повторной проверки опубликований федерального акта на
своей машине:

```
python scripts/pravo_lookup.py blocks              # список издающих органов — подтверждённый рабочий эндпоинт
python scripts/pravo_lookup.py search "98-ФЗ"       # поиск опубликований по номеру акта — схема ответа не подтверждена
python scripts/pravo_lookup.py amendments "98-ФЗ"
```

Портал `publication.pravo.gov.ru` недоступен из песочниц агентов на этом
проекте (похоже на геоблок не-российских адресов) — запускайте скрипт со
своей машины. Скрипт честно сообщает, если поиск недоступен или его схема
не подтверждена, а не выдумывает результат.

## Структура

```
SKILL.md                              # маршрутизатор — грузить сюда, не в references/ напрямую
references/
  commercial-secrecy.md               # 98-ФЗ, NDA, режим коммерческой тайны
  norms-registry-statutes.md
  personal-data.md                    # 152-ФЗ
  norms-registry-personal-data.md
  corporate.md                        # 14-ФЗ, корпоративный договор, ЕГРЮЛ
  norms-registry-corporate.md
  pre-litigation.md                   # претензионный порядок, исковая давность
  norms-registry-procedure.md
scripts/pravo_lookup.py
docs/BRIEF.md                         # сводный бриф проекта и решения по scope
```

## Статус

Контент написан (Codex, `work` mode, под литеральными брифами в `docs/`),
механически проверен (размеры файлов, отсутствие битых внутренних ссылок,
отсутствие затронутых посторонних файлов). Пройден цикл RED→GREEN→REFACTOR
(давящее тестирование Sonnet-сабагентами, по одному сценарию на самый
рискованный пункт каждой из четырёх веток) — 2026-09-10; см. `docs/BRIEF.md`,
раздел «Testing», и `ru-legal-skills/docs/review-checklist.md` за статусом
по всей семье скиллов.
