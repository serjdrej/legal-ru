# legal-ru

Если вы ведёте юридическую сторону бизнеса сами — без штатного юриста на
подхвате — приходится и проверять входящие NDA, и следить за 152-ФЗ при
сборе персональных данных, и оформлять решения участников ООО, и не
пропустить срок претензии. Без чёткой методики ИИ-ассистент обычно уверенно
подтверждает, что подписанный NDA уже защищает коммерческую тайну — хотя без
мер режима коммерческой тайны по ст.10 98-ФЗ это не так — либо называет
процессуальный срок как факт, а не как черновой ориентир для проверки. Этот
Agent Skill для Claude Code покрывает пять областей, где основателю
приходится действовать самостоятельно: контракты и режим коммерческой тайны
(98-ФЗ, NDA), персональные данные (152-ФЗ), корпоративное (14-ФЗ,
корпоративный договор, ЕГРЮЛ), договор подряда/строительный подряд (Глава 37
ГК РФ, сторона подрядчика) и досудебное/процессуальное (претензионный
порядок, исковая давность). Интеллектуальная собственность вне периметра —
см. `patent-ru`; процесс в государственном суде после претензии — см.
`arbitrazh-ru`.

Структура и часть формулировок изучены и частично адаптированы из
[`anthropics/claude-for-legal`](https://github.com/anthropics/claude-for-legal)
(Apache-2.0) — см. [NOTICE.md](NOTICE.md). Юридическое содержание не переведено
из этого источника: написано заново, с опорой на собственный реестр норм.

Каждый содержательный результат — черновик для проверки квалифицированным
юристом, а не юридическая консультация.

## Чего НЕ делает

- **Не замена юриста.** Каждый содержательный результат — черновик для
  проверки квалифицированным юристом, а не готовая юридическая позиция.
- **Не покрывает интеллектуальную собственность** — патенты, товарные
  знаки, изобретения вне периметра; для этого — отдельный скилл `patent-ru`.
- **Не полный ТК РФ.** Трудовое право затронуто только в объёме, нужном
  веткам выше (данные работника, ограничения конфиденциальности) — не
  отдельная ветка по трудовым спорам или увольнениям.
- **Не полное покрытие корпоративного права.** Ветка `corporate.md` — это
  ООО и точки соприкосновения с АО, не самостоятельное руководство по
  акционерным обществам.
- **Не восемь из двенадцати групп исходного `claude-for-legal`.** Сюда
  сознательно не перенесены `law-student`, `legal-clinic`,
  `legal-builder-hub` и более глубокая litigation-машинерия — см. `NOTICE.md`.
- **Реестры сами по себе не проверены.** Каждая запись в
  `references/norms-registry-*.md` помечена как непроверенная по живому
  источнику — сверка требует запуска `scripts/pravo_lookup.py` и
  `scripts/ips_lookup.py`. Агент, работающий локально, обязан запускать их
  сам перед тем, как опереться на запись (см. `SKILL.md`, «Живая
  перепроверка»), а не только советовать это пользователю.

## Как установить

**Через маркетплейс, Claude Code:**
```
/plugin marketplace add serjdrej/ru-legal-skills
/plugin install legal-ru@ru-legal-skills
```

**Через маркетплейс, Codex CLI:**
```
codex plugin marketplace add serjdrej/ru-legal-skills
codex plugin add legal-ru@ru-legal-skills
```

Обе команды читают один и тот же `ru-legal-skills/.claude-plugin/marketplace.json`
— проверено вживую на обоих рантаймах.

**Отдельно, без маркетплейса** — склонировать репозиторий в директорию
скиллов Claude Code (`~/.claude/skills/legal-ru` — на других CLI-рантаймах
может отличаться, см. их документацию):
```
git clone https://github.com/serjdrej/legal-ru.git ~/.claude/skills/legal-ru
```

### Необязательно: работа с PDF

Здесь — что поставить. Порядок самой работы (что проверять первым, как
отличить скан, что делать без извлекателя) — в
[`references/pdf-workflow.md`](references/pdf-workflow.md), он адресован
агенту, а не вам.

Скрипты работают на стандартной библиотеке Python и **ничего ставить не
требуют**. Но эта работа — работа с чужими документами: договоры,
акты выполненных работ, претензии, выписки ЕГРЮЛ, уставы, протоколы, а
изредка — официальная публикация закона, если `scripts/ips_lookup.py` не дал
текста нужной редакции. Два инструмента сильно меняют цену вопроса. Оба
**необязательны**, ставятся вами и живут на вашей машине; ни один скрипт
репозитория их не импортирует.

**Извлечение текста.**

```
pip install pymupdf
```

Без извлечения текста многостраничный документ читается страницами как
изображения — на практике не читается вовсе. С извлекателем нужное
достаётся адресно. PyMuPDF здесь — сегодняшний рабочий вариант, а не
единственный: подойдёт любой инструмент, отдающий корректную кириллицу.
Стандартная библиотека Python её не отдаёт.

**Распознавание сканов** — [Tesseract](https://github.com/tesseract-ocr/tesseract),
Apache 2.0. Для этого скилла это не редкий случай: официальные публикации
закона на `publication.pravo.gov.ru` — измерено сессией маркетплейса
2026-09-23 на шести актах, все шесть оказались сканами без текстового слоя
(пять как PDF, один как ZIP с постраничным TIFF), тогда как у
`arbitrazh-ru` PDF с `vsrf.ru` наоборот всегда с текстом. Входящие документы доверителя —
скан или нет, не измерено, проверяйте каждый отдельно. Две ловушки при
установке: движок и языковые данные ставятся **по отдельности**, а
установщик под Windows кладёт только английский — без `rus` распознавание
кириллицы даёт правдоподобный мусор. Распознанный текст — гипотеза о
содержании документа: номер статьи или части из OCR не идёт в реестр норм
без сверки по изображению (см. `references/pdf-workflow.md` — надстрочные
номера частей статьи там путаются особенно легко).

**Почему не в зависимостях.** PyMuPDF распространяется под AGPL-3.0 либо
коммерческой лицензией Artifex, а этот репозиторий — под MIT. Разбирать,
что именно следует из такого сочетания для каждого, кто поставит плагин, —
не задача этого README; проект выбрал не доводить до вопроса и зависимости
не берёт. У Tesseract лицензия разрешительная (Apache 2.0), но это внешняя
программа, а не библиотека Python. Скилл пользуется тем, что есть, и
честно говорит, чего лишается, если чего-то нет.

Что из лицензий следует для вашей установки на вашей машине — решаете вы.
Скилл называет лицензию и на этом останавливается: юридические выводы за
пользователя он не делает независимо от того, кто он.

**Молча агент ничего не ставит.** Если инструмента нет, он скажет, что тот
даёт, во что обойдётся работа без него, назовёт команду и лицензию — и
продолжит доступным способом. Ответите «ставьте» — поставит: это ваша
машина и ваше решение. Согласие относится к этой установке, а не ко всем
будущим.

## Проверка актуальности нормы

Ни одна запись ни в одном реестре (`references/norms-registry-*.md`) не
сверена по живому источнику — каждая явно это говорит и объясняет, как
перепроверить. Скрипт реально работает (проверено 2026-09-14) — если вы
запускаете скилл локально, запускайте его сами перед тем, как опереться на
запись, а не только упоминайте пользователю:

```
python scripts/pravo_lookup.py blocks                          # список издающих органов
python scripts/pravo_lookup.py search "98-ФЗ"                  # точный поиск по номеру — номер не уникален по годам, скрипт покажет все совпадения с датами
python scripts/pravo_lookup.py by-title "коммерческой тайне"   # поиск по названию — находит закон и поправки к нему
```

Раньше здесь было написано, что портал недоступен из песочниц агентов
(«геоблок») — это была ошибка диагностики: реальная причина в том, что
`https://` на этом хосте зависает, а `http://` отвечает мгновенно (скрипт
уже использует `http://`). Облачные инструменты вроде WebFetch всё ещё не
достучатся (они принудительно апгрейдят `http://` в `https://`) — это
ограничение конкретных инструментов, не портала.

### Если нормы нет ни в одном реестре

Ситуация отдельная от «нужно перепроверить дату» выше: реестры покрывают
пять веток (коммерческая тайна/NDA, персональные данные, корпоративное,
подряд, претензионное), и запросы за их пределами — например, вопрос по
другой юрисдикции или по области права, для которой в этом скилле нет
ветки — не должны отвечаться по памяти как будто это проверенная норма.
`SKILL.md` содержит «Протокол пробела в базе»: если тема ещё в рамках
федерального законодательства РФ, скилл сначала ищет её живьём через
`by-title` и помечает находку как **AD HOC** (слабее любой записи реестра);
если нет — прямо говорит об этом и спрашивает, как продолжать, вместо
того чтобы выдумывать ответ.

  norms-registry-statutes.md
  personal-data.md                    # 152-ФЗ
  norms-registry-personal-data.md
  corporate.md                        # 14-ФЗ, корпоративный договор, ЕГРЮЛ
  norms-registry-corporate.md

  norms-registry-podryad.md

  norms-registry-procedure.md

scripts/
  pravo_lookup.py                     # publication.pravo.gov.ru — публикации и поправки, не текст статьи
