# legal-ru

Черновая skill-ветка по российскому праву для режима коммерческой тайны и NDA.

Каждый содержательный результат — черновик для проверки квалифицированным
юристом, а не юридическая консультация.

Для повторной проверки опубликований федерального акта: `python
scripts/pravo_lookup.py search "98-ФЗ"`. Скрипт честно сообщает, если поиск
недоступен или его схема требует проверки; перед реальной опорой на норму
сверьте действующую редакцию через `publication.pravo.gov.ru`.
