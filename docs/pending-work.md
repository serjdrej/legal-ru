# Отложенная работа по этому скиллу

Задачи и рекомендации для того, кто возьмёт `legal-ru` следующим. Кладутся в
репозиторий, а не в переписку: просьба, живущая в чужом контексте, живёт до
ближайшего компакта.

---

## Рекомендация: правило «Как править этот файл» в `SKILL.md`

**Оставил:** ведущая сессия маркетплейса `ru-legal-skills`, 2026-09-19, по
поручению владельца. **Это рекомендация, а не наряд** — текст в вашем
`SKILL.md` ваше решение, и обоснованный отказ ценится наравне с согласием.

### Что предлагается

Единственная рекомендация из разбора «что из `arbitrazh-ru` стоит
раскатать» (`ru-legal-skills/docs/DRAFT-arbitrazh-rollout.md`), добавляющая
текст в чужой `SKILL.md`. 533 знака, 9 строк, как стоит у автора:

> ## Как править этот файл
>
> Новая оговорка пишется туда, где будет читатель в момент ошибки. Носители
> по убыванию предпочтения: **(1)** поле в выводе скрипта — оно приходит с
> данными и закрывается тестом; **(2)** файл в `references/`, который маршрут
> обязывает открыть; **(3)** этот файл. Выбор (3) требует назвать, почему (1)
> и (2) не подходят. Поле не может нести то, что нужно **до** вызова: агент,
> не вызвавший скрипт, поля не увидел. Этот файл вырос с 225 строк до 498 за
> один день, и вернётся туда же, если правило не соблюдать.

### Почему это не дубль §10 конвенции

Те же три ступени в конвенции есть, но она адресована **сопровождающему,
читающему её изредка**. Здесь правило стоит там, где находится **агент в
момент правки**. По логике самой §10 — носитель решает — это её применение
к себе, а не повтор.

### Основание именно для этого репозитория

Проверено ведущей сессией 2026-09-19 этими командами:

```
git show $(git log --diff-filter=A --format=%H -- SKILL.md | tail -1):SKILL.md | wc -c
wc -c < SKILL.md
```

2 249 → 19 428 байт, **рост ×8,6** — самый крутой из трёх соседей
(`patent-ru` ×2,7, `gost-ed-mashiny` ×2,6) и почти вровень с автором правила
(×9,3). Разница в том, что тормоз есть только у него.

Разбор отдельно отметил здесь два раздела, выросших добавлением абзацев
именно в `SKILL.md`: «Жёсткие правила» и «Протокол пробела». Не потому что
абзацы неверные, а потому что правила, куда их класть, нет.

### Чего переносить нельзя

**Последнюю фразу — «вырос с 225 строк до 498» — как есть переносить
нельзя:** это факт про `arbitrazh-ru`. По §8 конвенции на её месте должно
стоять либо собственное число (команда выше), либо та же цифра с указанием
источника и даты. Иначе получится неатрибутированный замер — ровно то, против
чего §8 написана.
