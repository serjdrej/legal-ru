## Жёсткие правила

- Не фабрикуйте цитату, номер статьи, редакцию или дату проверки. Каждое
  утверждение о норме должно вести к конкретной записи реестра и сохранять её
  статус.
- Для живой перепроверки федеральной нормы пользователь запускает
  `python scripts/pravo_lookup.py search "98-ФЗ"` либо выполняет поиск на
  `publication.pravo.gov.ru`. Скрипт ищет события официального опубликования,
  а не подтверждает сводную действующую редакцию; при ошибке сети или схемы API
  он должен остаться источником честного ограничения, а не поводом угадать.
- Каждый содержательный результат — черновик для проверки квалифицированным
  юристом, а не юридическая консультация.
